# Feature status

This is an initial coarse inventory; expand into individual acceptance criteria
before implementing each area. Library code alone is not a complete user feature.

| Feature | Phase | Status | Evidence / next test |
| --- | --- | --- | --- |
| GPUI desktop window | 0 | In progress | Host manager, Add/Edit forms with groups/tags/jump-hosts, real-time search filter, Quick Connect bar, mouse refresh and Command-R checked on macOS; split panes and terminal search implemented; screen-reader and other platforms need validation |
| Security architecture | 0 | In progress | See security/threat-model.md; memory zeroization on drop verified for Ed25519 private keys and SecretString; host key verification engine implemented; OS Keychain integration active on macOS; security warnings before exposing tunnel bindings beyond localhost |
| SSH and host verification | 1 | In progress | CLI and GPUI session dispatch to OpenSSH with `StrictHostKeyChecking=ask`, `ForwardAgent=no`, and `-J` jump host chaining; pure Rust OpenSSH `known_hosts` verification engine implements trusted, TOFU, changed-key MITM risk, and revoked key detection with unit tests; isolated OpenSSH test covers live server authentication |
| Local terminal | 1 | Implemented | Cross-platform PTY manager (`portable-pty`) and VT/ANSI terminal emulator (`shellumi-terminal`) with 13 unit tests; GPUI app features a "Local terminal" button, session worker with resize and input dispatch, clipboard paste (`Cmd-V`/`Ctrl-Shift-V`), extended ANSI key navigation, styled text span rendering (16/256/TrueColor RGB and attributes), scrollback buffer, live status bar, and in-terminal search engine with highlighted matches |
| Host storage and metadata | 2 | In progress | Turso local database with transactional migrations (schema version 8, auto-migration from versions 1, 2, 3, 4, 5, 6, and 7); persistent `HostGroup` storage (`groups` table), jump hosts, persistent startup snippets (`hosts.startup_snippet_id` foreign key referencing `snippets(id)` ON DELETE SET NULL), persistent SSH tunnels (`tunnels` table), transfer audit history (`transfer_history` table), snippets and templates (`snippets` table), disaster recovery snapshots (`sync_snapshots` table with `archive_snapshot`, `list_snapshot_history`, `get_snapshot_vault`, and `rollback_snapshot`), configuration inheritance (`get_effective_destination`, `get_effective_tags`), tags, filtering, search, and CRUD operations tested in storage, CLI (`show <id>`, `group add/list/show/delete`, `tunnel add/list/delete`, `sftp history/log`, `snippet add/list/show/render/delete`, `vault history/rollback`), and GPUI; OpenSSH config (`~/.ssh/config`) and RFC 4180 CSV import/export verified |
| Quick Connect | 2 | Implemented | Instant destination parsing (`user@host[:port]`) in `shellumi-core`, `quick-connect` command in `shellumi-cli`, and Quick Connect toolbar in `shellumi-app` |
| Key generation & management | 2 | In progress | Pure Rust Ed25519 key generation via `ring`, OpenSSH wire format encoding, SHA-256 fingerprinting, memory zeroization on drop (`zeroize::Zeroizing`), `shellumi-cli keygen` command, multi-platform credential stores (`MacOsKeychainStore`, `WindowsCredentialManagerStore`, `LinuxSecretServiceStore`), and portable `EncryptedFileCredentialStore` with AES-256-GCM AEAD and PBKDF2-HMAC-SHA256 unified under `default_credential_store()` tested |
| Workspaces and terminal | 3 | In progress | Multi-tab session manager supports concurrent local, SSH, and SFTP terminal tabs with background execution, tab switching, Hosts view toggling, tab closure, index tracking, vertical and horizontal split panes with independent PTY sessions, active focus outlines, pane search toolbar with forward/backward match navigation, and collapsible in-terminal Snippets drawer |
| SFTP, tunnels, proxies | 4 | In progress | Pure Rust SSH port forwarding models (`PortForwardRule`: Local, Remote, Dynamic SOCKS5) with localhost exposure security warnings; jump host chain validation (`validate_jump_host`); RFC SFTP v3 wire protocol packet codecs (`SftpPacket`, `StatusCode`, `OpenFlags`, `FileAttributes`, `NameEntry`), stream framing with partial-buffer detection and length bounds validation (`WireReader`), concurrent transfer queue orchestration (`TransferQueue`), `FileEntry`, permissions, byte formatting, breadcrumbs, path normalization, `TransferTask`, and `list_local_directory`; Turso database schema v6 with persistent `jump_host`, `tunnels`, and `transfer_history` tables; CLI subcommands (`sftp local-ls`, `history`, `clear-history`, `log`, `packet encode-init/decode/encode-open`, `queue`); and a full GPUI graphical dual-pane SFTP file manager (Local left pane, Remote right pane, breadcrumbs, up-navigation, hidden-files toggling, selection-driven Upload/Download actions, live transfer queue drawer with visual progress bar, and mode switching between Dual-Pane View and interactive terminal) |
| Encrypted Google Drive sync | 5 | In progress | Zero-knowledge PBKDF2-HMAC-SHA256 KEK derivation with memory zeroization on drop, AES-256-GCM AEAD envelope sealing with bound associated data, versioned `SyncRecord` models with deletion tombstones, three-way sync conflict detection (`determine_sync_action`), RFC 7636 PKCE challenge generation, loopback HTTP OAuth listener (`OAuthCallbackListener`) with CSRF verification and HTML feedback, token bundle expiration management and secure credential store persistence (`OAuthTokenBundle::save_to_store`, `load_from_store`, `delete_from_store`), payload-decrypting record diff engine (`diff_sync_records_with_passphrase`), `SyncVault` snapshot export/import in `shellumi-storage`, CLI `vault export/import/diff/status/oauth-url/history/rollback` subcommands, Google Drive AppData REST API client (`GoogleDriveSyncClient`), conflict-safe sync planner (`plan_sync_cycle`, `SyncPlan`), GPUI in-window sync status badge with background executor dispatch, explicit conflict resolution strategies (`resolve_record_conflict`, `ConflictResolutionChoice`), an interactive Conflict Resolution Modal with side-by-side visual diff cards in `shellumi-app`, disaster recovery snapshots with history and rollback (`sync_snapshots` table, schema v7), and automated background periodic sync timer loop (`SyncScheduler` with 5s local debounce and 300s polling) |
| Snippets and automation | 6 | In progress | Pure Rust snippet parsing and variable extraction (`{{var}}`, `{{var:-default}}`), POSIX shell escaping (`shell_escape`), secret variable auto-detection, preview redaction (`render_preview`), and JSON library export/import in `shellumi-core`; persistent `snippets` table with search and tags in `shellumi-storage` (schema v8); persistent host startup snippets (`hosts.startup_snippet_id`) with automatic property substitution (`{{host.id}}`, `{{host.name}}`, `{{host.hostname}}`, `{{host.username}}`, `{{host.port}}`, `{{host.group}}`, `{{host.tags}}`) and auto-execution on connection in GPUI and CLI; CLI commands `snippet add/list/show/render/delete/batch` with `--var`, `--preview`, and `--hosts` multi-host batch execution/dry-run flags; multi-host batch runner in `shellumi-core::batch` (`BatchHostTarget`, `BatchPolicy`, `BatchExecutionPlan`, `BatchRunner`, `BatchExecutionSummary`); collapsible `📜 Snippets` drawer in `shellumi-app` with Paste, Run, and Multi-Host execution; interactive GPUI Snippet Variable Modal prompt (`SnippetModalState`); and desktop Multi-Host Batch Execution Modal (`BatchModalState`) with target filtering, selection toggles, policy choices, dry-run previews, and background execution with per-host status and expandable output cards |
| Command palette | 6 | Implemented | Decoupled palette action and fuzzy search scoring engine in `shellumi-core::palette` (`PaletteRegistry`, `PaletteCategory`, `PaletteCommand`, `PaletteAction`) with tokenized scoring and acronym resolution; CLI `palette search` subcommand; full GPUI desktop Command Palette modal overlay (`CommandPaletteState`) bound globally to `Cmd-K` (macOS) / `Ctrl-K` (Linux/Windows) and accessible via top navigation buttons across Hosts and Terminal views, with full keyboard navigation (Up/Down/Enter/Esc), and direct action dispatch for SSH/SFTP connections, snippet execution, multi-host batch execution (`PaletteAction::ExecuteBatchSnippet`), Cloud Sync triggering, pane splitting, and tab switching |
| Mosh, Telnet, serial | 7 | Not started | Protocol-specific integration tests |
| Collaboration | 8 | Not started | Authorization and cryptographic review |
| Infrastructure integrations | 9 | Not started | Provider fixtures and permission tests |
| Release hardening | 10 | Not started | Cross-platform builds, security review, packaging |
| Mobile feasibility | 11 | Not started | Validate GPUI and platform lifecycle support |
