Open **Settings** (`Cmd+,` / `Ctrl+,`) to configure:

- **Appearance & Terminal:** UI font size, terminal font size, scrollback capacity, default startup page, and hidden-file visibility.
- **Storage & Backups:** Active vault database path (`*.preferences.json` stored beside each database) and encrypted local backup export/restore.
- **Synchronization:** Opt-in Google Drive sync controls and Shellumi Server connection settings.
- **Security & Tools:** Known-host trust policy notes, shell integration hooks (Bash, Zsh, Fish), keyboard shortcut reference, and runtime diagnostics.
