Open **Session Logs** to inspect, play back, export, or delete opt-in Asciicast v2 terminal recordings:

- **Recording:** Opt-in per session; captures timestamped terminal output.
- **Playback:** Play, pause, seek, and adjust playback speed (`0.5x`–`4x`) in the Session Replay view.
- **Export / Import:** Export recordings as `.cast` files or import existing Asciicast v2 files with optional redaction.

> [!WARNING]
> Automated redaction reduces accidental secret capture but does not guarantee that recorded terminal output contains zero sensitive data. Treat `.cast` files as sensitive artifacts.
