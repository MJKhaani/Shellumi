---

Workspaces (`Cmd+Shift+K` / `Ctrl+Shift+K`) let you save and reopen multi-session layouts (`Single`, `Vertical`, `Horizontal`, or `Grid`) combining saved hosts and local shells.

- **Create / Duplicate / Edit:** Manage layouts via the Workspace Inspector.
- **Launch:** Opening a workspace starts fresh sessions for the configured panes; remote processes from prior runs are not restored.
