# Documentation Assets

Shared visual assets, screenshots, and diagram references used across Shellumi documentation.

> **Icon Pack Source of Truth:** Product and protocol icons reside in [`resources/icon_pack/icons/`](../../resources/icon_pack/icons/) (`32`, `48`, and `64` px PNGs). Documentation embeds those canonical assets directly rather than duplicating icon files.

## Subdirectories

| Directory | Purpose |
| --- | --- |
| [Diagrams](diagrams/README.md) | Diagram conventions (Mermaid-first) and any exported static diagrams. |
| [Screenshots](screenshots/README.md) | Application screenshots and capture guidelines. |
