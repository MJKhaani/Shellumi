# Documentation Diagrams

Shellumi documentation prefers inline **Mermaid** diagrams (`flowchart`, `sequenceDiagram`, `stateDiagram-v2`) so diagrams are version-controlled, diffable, and rendered natively on GitHub.

All Mermaid diagrams in `docs/` are checked for balanced fenced code blocks by `scripts/verify-docs.sh`.
