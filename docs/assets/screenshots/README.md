## Capture Guidelines

1. Use deterministic sample fixtures (never real user hosts, IP addresses, or credentials).
2. Capture at 2x Retina / crisp logical scaling with default dark theme unless illustrating a theme variant.
3. Verify no sensitive hostnames or personal paths appear in window titles or terminal buffers.
