# Keyboard Shortcuts Reference

[Docs Home](../README.md) / [Reference](README.md) / Keyboard Shortcuts

---

All shortcuts below are extracted directly from registered GPUI `KeyBinding`s in `crates/shellumi-app/src/main.rs` and `text_input.rs`.

## Global & Navigation

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **Command Palette** | `Cmd + K` | `Ctrl + K` |
| **Quick Connect** | `Cmd + O` | `Ctrl + O` |
| **New Host** | `Cmd + N` | `Ctrl + N` |
| **Refresh Inventory** | `Cmd + R` | `Ctrl + R` |
| **Settings / Preferences** | `Cmd + ,` | `Ctrl + ,` |
| **Toggle Sidebar** | `Cmd + \` | `Ctrl + \` |
| **Collapse Sidebar** | `Cmd + Shift + \` | `Ctrl + Shift + \` |
| **Open Vault in New Window** | `Cmd + Shift + N` | `Ctrl + Shift + N` |
| **Go to Hosts** | `Cmd + Shift + H` | `Ctrl + Shift + H` |
| **Go to Overview** | `Cmd + Shift + O` | `Ctrl + Shift + O` |
| **Go to Workspaces** | `Cmd + Shift + K` | `Ctrl + Shift + K` |
| **Go to SFTP Files** | `Cmd + Shift + U` | `Ctrl + Shift + U` |
| **Go to Keychain** | `Cmd + Shift + Y` | `Ctrl + Shift + Y` |
| **Go to Port Forwarding** | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| **Quit Application** | `Cmd + Q` | `Ctrl + Q` |

## Tabs & Split Panes

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **New Tab** | `Cmd + T` | `Ctrl + T` |
| **Open Local Terminal** | `Cmd + L` | `Ctrl + L` |
| **Close Tab** | `Cmd + W` | `Ctrl + W` |
| **Next Tab** | `Cmd + Shift + ]` / `Ctrl + Tab` | `Ctrl + Tab` / `Ctrl + PageDown` |
| **Previous Tab** | `Cmd + Shift + [` / `Ctrl + Shift + Tab` | `Ctrl + Shift + Tab` / `Ctrl + PageUp` |
| **Select Tab 1–9** | `Cmd + 1` … `Cmd + 9` | `Ctrl + 1` … `Ctrl + 9` |
| **Reconnect Session** | `Cmd + Shift + R` | `Ctrl + Shift + R` |
| **Split Vertical** | `Cmd + D` | `Ctrl + Shift + E` |
| **Split Horizontal** | `Cmd + Shift + D` | `Ctrl + Shift + O` |
| **Focus Next / Previous Pane** | `Cmd + ]` / `Cmd + [` | `Alt + Right` / `Alt + Left` |
| **Close Active Pane** | `Cmd + Shift + W` | `Ctrl + Shift + W` |
| **Toggle Focus Mode** | `Cmd + Shift + M` | `Ctrl + Alt + M` |
| **Toggle Broadcast Input** | `Cmd + B` / `Cmd + Shift + B` | `Ctrl + Alt + B` |
