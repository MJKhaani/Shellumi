# Requirement Migration Inventory

This inventory maps every section of the original master specification ([`master-project-specification.md`](../../archive/implementation-plans/master-project-specification.md), `3123db2:PROJECT.md`) to stable `REQ-*` identifiers, current authoritative destinations, implementation status, evidence, and acceptance criteria.

## Status Legend

- **Implemented:** Core logic and UI/CLI surface implemented and covered by automated unit/integration tests.
- **Partial:** Core or scaffolding implemented, with documented gaps, missing live-server verification, or incomplete UI/transport paths.
- **Experimental:** Initial prototype or opt-in support; not stabilized for production reliance.
- **Planned:** Preserved requirement not yet implemented.
- **Superseded:** Replaced by an explicit later architectural decision (documented with rationale).
